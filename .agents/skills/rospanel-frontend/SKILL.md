# RosPanel Frontend Development Guide

Используйте этот навык при разработке, рефакторинге или дизайне пользовательского интерфейса панели администрирования RosPanel (`web/`).

---

## 1. Технологический стек

- **Фреймворк**: React 19 + TypeScript.
- **Стилизация**: Tailwind CSS v4 (`@tailwindcss/vite`).
- **Линтинг и форматирование**: Biome (`biome.json`). Никаких лишних ESLint/Prettier конфигов.
- **Компоненты и графики**: Recharts (для сетевых графиков трафика), CodeMirror (для редакторов скриптов/конфигов), `web/src/ui.tsx` (базовые UI-примитивы).
- **Связка с бэкендом**: сборка в `web/dist`, встраивание в Go-бинарник через `web/embed.go`.

---

## 2. Дизайн-система и принципы верстки панели

RosPanel — инженерная административная панель для мониторинга и управления прокси-инфраструктурой, серверами и подписками.

1. **Информационная плотность и эргономика**:
   - Интерфейс ориентирован на системных администраторов: плотные таблицы, понятные индикаторы статусов, быстрый доступ к копированию ссылок и ключей.
   - Используйте карточную структуру (`Card` из `ui.tsx`) для группировки логических блоков настроек.
2. **Цветовая палитра и темы**:
   - Панель по умолчанию оптимизирована под тёмную тему с высокой контрастностью данных.
   - Статусные индикаторы:
     * Зеленый (`emerald`/`green`): сервер в сети, протокол активен, трафик в норме.
     * Желтый/Оранжевый (`amber`/`yellow`): частичная деградация, приближение к лимиту квоты, синхронизация.
     * Красный (`rose`/`red`): нода недоступна, ошибка применения конфига Xray, блокировка.
     * Серый (`zinc`/`slate`): отключено, сервис на паузе.
3. **Использование базовых UI-примитивов (`web/src/ui.tsx`)**:
   - Не создавайте кастомные кнопки или текстовые инпуты с нуля. Используйте готовые компоненты проекта: `Button`, `TextInput`, `Select`, `Modal`, `Switch`, `Badge`, `Card`.
   - Это гарантирует единый радиус скруглений, анимацию фокуса и стили наведения.

## 3. Обязательная интернационализация (5 языков)

Вся панель поддерживает 5 языков:
- `ru` (Русский)
- `en` (Английский)
- `fa` (Фарси / RTL)
- `ar` (Арабский / RTL)
- `zh` (Упрощённый китайский)

### Правила добавления текста:
1. **Никакого хардкода**: никогда не пишите сырой текст на русском или английском в TSX-разметке:
   ```tsx
   // ПЛОХО:
   <Button>Сохранить маршрут</Button>
   
   // ХОРОШО:
   const { t } = useTranslation();
   <Button>{t('multihop.saveRoute')}</Button>
   ```
2. **Атомарность словарей**: новый ключ должен быть добавлен **одновременно во все 5 файлов**:
   - `web/src/i18n/ru.ts`
   - `web/src/i18n/en.ts`
   - `web/src/i18n/ar.ts`
   - `web/src/i18n/fa.ts`
   - `web/src/i18n/zh.ts`
3. **RTL-адаптивность**: учитывайте направление текста для `fa` и `ar`: избегайте жестких отступов `pl-*` / `pr-*`, где уместнее `ps-*` / `pe-*` (start/end) или flexbox gap.

## 4. Пайплайн валидации изменений

Перед отправкой изменений в git обязательно выполните последовательно:

```bash
# 1. Проверка типов TypeScript:
npm --prefix web run typecheck

# 2. Проверка линтером Biome:
npm --prefix web run lint

# 3. Автоисправление мелких стилей (при необходимости):
npm --prefix web run lint:fix

# 4. Проверочная сборка (генерирует dist для встраивания в Go):
npm --prefix web run build
```
