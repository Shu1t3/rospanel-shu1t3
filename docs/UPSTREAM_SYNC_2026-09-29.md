# Интеграция upstream 4.1.0–4.2.0

Интеграционная ветка: `codex/upstream-v4.2-sync`.
База форка: `a95819c` (4.0.3).
База предыдущей синхронизации: `2d36093`.
Источник: [AppsGanin/rospanel, e12b2c9](https://github.com/AppsGanin/rospanel/commit/e12b2c9).

Выполнен merge истории upstream без переписывания коммитов форка.

## Перенесено

- Кошелёк, промокоды, рефералы, возвраты и аналитика продаж.
- Гибкие тарифы: дополнительные устройства, пакеты трафика и смена плана.
- YooMoney и Telegram Stars, журнал webhook платежей и анализ подозрительной активности.
- Telegram Mini App, мастер подключения, автоматические сообщения и общий чёрный список.
- Обновления панели и нод по расписанию, исправления подписок и валидации публичного порта Xray.

## Решения при пересечениях

- Сохранены модуль, адрес установки и источник обновлений форка.
- Сохранены более новые Go/frontend зависимости, включая pion/transport v5.1.1.
- Сохранены транзакционная регистрация, постраничная выборка пользователей, роли, переезд мастера, исправления UFW и порта 443.
- Расширены DTO тарифов и заказов: новые поля биллинга проходят через существующие HTTP контракты форка.
- Новые фоновые задачи запускаются на активном мастере. На standby отключены финансовые действия; fencing переключения мастера блокирует биллинг, автоматические сообщения и запуск автообновления.
- Сохранены имена и содержимое выпущенных миграций. Добавлены 12 миграций upstream; совпадающие числовые префиксы допустимы, поскольку журнал использует полные имена файлов.
- Версия 4.0.3 и release-please manifest остаются версией последнего опубликованного релиза форка; следующую версию определяет release-please.
- Одинаковые имена тегов форка и upstream не перезаписывались.

## Проверки

- Frontend: `npm run lint`, `npm run build`.
- Go: `go vet ./...`, `go build ./...`, кросс-сборка Linux amd64 с `CGO_ENABLED=0`.
- Race-тесты всех пакетов; после исправления фикстуры повторно проверены store/autoupdate/core/cmd, затем затронутые тесты автоматических сообщений.
- `golangci-lint v2.13.2 run`: 0 замечаний, включая полный репозиторий.
- `govulncheck`: 0 уязвимостей, вызываемых кодом; есть уведомления о неиспользуемых уязвимых символах зависимостей.
- Go code review кода адаптации: подтверждённые ошибки DTO/импортов/standby устранены; блокирующих замечаний не осталось.
- Регрессионные тесты перехода с БД 4.0.3 с сохранением данных и повторным запуском миграций, новых DTO, standby/fencing и автообновлений.

Проверки выполнены на macOS arm64. Внешние платежи, Telegram и перезапуск реального systemd сервиса не проверялись на production; их интеграционные сценарии покрыты автоматическими тестами с тестовыми транспортами и зависимостями. Обновление серверов этой работой не запускается.
