# Интеграция upstream v4.3.0 и последующих коммитов

База форка: `1d9e345`, опубликованная версия 4.1.0.
Предыдущая база upstream: `e12b2c9` (v4.2.0).
Источник: [AppsGanin/rospanel, 553291d](https://github.com/AppsGanin/rospanel/commit/553291d).

Выполнено слияние истории без переписывания коммитов и тегов форка.

## Перенесено

- Регистрация сайта через `/v1/signup` с invitation, moderation, rate limit, источником и реферером.
- Собственные права API-ключей и выбор точных методов; перенос прав ранее выпущенных ключей.
- Карточка доступа на странице подписки, дата окончания дополнительных устройств.
- Привязка и смена Telegram через подписку, подтверждение переноса чата и история использованного trial.
- SQLite 1.60.1; остальные зависимости остаются более новыми версиями форка либо уже совпадают с upstream.

## Решения при пересечениях

- Сохранены модуль, адрес установки, источник автообновлений, README и release workflow форка.
- Версия и manifest остаются 4.1.0 до выпуска следующей версии через release-please.
- Сохранена транзакционная Telegram-модерация; история trial фиксируется вместе с аккаунтом и решением заявки.
- Регистрация сайта и её модерация также выполняются транзакционно: аккаунт, external_id, тариф, источник, реферер и решение заявки записываются вместе. Уведомления отправляются после commit.
- Повторная Telegram-регистрация получает бесплатный тариф либо уже истёкший trial, если бесплатного тарифа нет.
- Конвертация старых API-ключей выполняется на активном мастере, фоновые задачи standby/fencing сохранены.
- Настройки привязки Telegram сбрасывают локальный кэш настроек.
- Добавлены неизменённые миграции upstream 0098–0102; прежние имена и контрольные суммы сохранены.

## Проверки

- Frontend: `npm ci`, `npm run lint`, `npm run build`.
- Go: `go vet ./...`, `go build ./...`, Linux amd64/arm64 с `CGO_ENABLED=0`.
- `go test -race ./...`; проверка обновления БД с 4.0.3 и 4.1.0 с повторным открытием. Один первый прогон сетевого server-теста встретил занятый временный UDP-порт; повторный прогон server и затем общий прогон прошли.
- Регрессионные тесты rollback/retry регистрации, повторного одобрения, сохранения существующего аккаунта и повторного Telegram trial.
- `golangci-lint v2.13.2`: 0 замечаний.
- `govulncheck`: 0 уязвимостей вызываемых символов; есть уведомление об уязвимости неиспользуемых символов зависимостей.

Локальная платформа: macOS arm64. Реальные платежи, Telegram и перезапуск production systemd не проверялись; используются автоматические тесты с тестовыми транспортами. Внешний Playwright smoke suite требует отдельного запущенного и наполненного стенда и не запускался.
